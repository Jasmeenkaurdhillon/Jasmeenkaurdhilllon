# Learning roadmap (8 weeks, about 1–1.5 hours a day)

**Learn → see it in code → test yourself.**

- **Notes** = the `study-notes` folder
- **NB1** = `01_Mobile_App_Development.ipynb`
- **NB2** = `02_Usability_UX_Exercises.ipynb`

## Daily routine

- [ ] **10 min**: quiz in the notebook (`ask()`, then `reveal()`)
- [ ] **30–40 min**: read one notes section, then close it. Write the key lists from memory, then check.
- [ ] **20–30 min**: find the matching code in NB1. Type it yourself into a new page or file instead of only reading it. The Mobile App exam is written, so practise writing code by hand.
